# חילוץ ועיבוד הרצאות וידאו – בקרה אופטימלית (Whiteboard Lecture System)

מערכת אוטומטית מקצה-לקצה לעיבוד הקלטות וידאו של הרצאות אקדמיות (קורס **בקרה אופטימלית**), שיפור איכות השמע, חילוץ מדויק של לוחות הכיתוב באמצעות ראייה ממוחשבת (Computer Vision & Deep Learning), והפקת סיכומי לוח וחוברות העמקה פדגוגיות בפורמט Markdown ו-LaTeX.

## 🚀 איך לעבד הרצאה חדשה? (מדריך לאג'נט / למשתמש)

כאשר מתווסף קובץ וידאו חדש של הרצאה (למשל `הרצאה 3.mp4`), פועלים לפי השלבים הבאים:

### שלב 1: חילוץ לוחות נקיים ללא המרצה
```powershell
$env:PYTHONIOENCODING="utf-8"; python whiteboard_extractor.py "הרצאה 3.mp4" --interval 6 --output-dir "extracted_board_temp"
```
*המנוע יבצע ייצוב מצלמה, יסנן פריימים מטושטשים, יעלים את המרצה ויישמור תמונות לוח נקיות עם קובץ `keyframes_manifest.json`.*

### שלב 2: תמלול הלוח למסמך `סיכום_לוח_הרצאה_X.md`
יש לקרוא את קובץ המניפסט ולעבור על הפריימים הכרונולוגיים כדי להקליד את הנוסחאות ב-LaTeX תקני, תוך שמירה על סימוני המרצה (וקטורים עם קו תחתי $\underline{x}$, נורמות משוקללות).

### שלב 3: הפקת חוברת הסברים והעמקה פדגוגית
מזינים את סיכום הלוח לסוכן AI יחד עם הפרומפט המופיע בקובץ [`PROMPT_AGENT_EXPLANATIONS.md`](PROMPT_AGENT_EXPLANATIONS.md).
הסוכן מייצר חוברת לימודית הכוללת:
1. אינטואיציה ומוטיבציה הנדסית.
2. מילון סימונים ומשמעותם.
3. דוגמאות פיזיקליות (רחפנים, טילים, מנועים).
4. הקפדה מלאה על שורות רווח ריקות סביב כל בלוק `$$...$$` למניעת באג כיווניות עברית (BiDi).
