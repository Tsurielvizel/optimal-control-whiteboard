# חילוץ כיתוב מתמטי ועברי מלוח הרצאות וידאו (Whiteboard Lecture Extractor)

מערכת פייתון לעיבוד הקלטות וידאו של הרצאות אקדמיות (כגון הקורס **בקרה אופטימלית**), שיפור איכות השמע שלהן, וחילוץ אוטומטי של הכיתוב המתמטי והעברי שעל הלוח לתמונות נקיות (ללא הסתרת המרצה) ולקובצי סיכום בפורמט Markdown (`.md`) הכוללים נוסחאות LaTeX.

---

## תכולת המאגר

| קובץ | תיאור |
| :--- | :--- |
| [`whiteboard_extractor.py`](whiteboard_extractor.py) | מנוע הראייה הממוחשבת המרכזי: ייצוב מצלמה (`phaseCorrelate`), הסרת המרצה לאורך זמן באמצעות `YOLOv8-seg` (`temporal_deocclusion`), נרמול תאורה גאוסיאני, וסינון כפילויות מבוסס שימור דיו. |

## התקנה ושימוש מהיר

```bash
pip install -r requirements.txt
```

### חילוץ פריימי-מפתח נקיים מלוח הרצאה (ללא המרצה):
```bash
python whiteboard_extractor.py "בקרה אופטימלית - שעור 1 _ דף הבית.mp4" --start 00:00 --end 30:00 --output-dir extracted_board
```

### הרצת השוואה מלאה בין 3 השיטות (Benchmark):
```bash
python compare_methods.py "בקרה אופטימלית - שעור 1 _ דף הבית.mp4" --start 52:00 --end 67:00
```

### שיפור איכות השמע של הקלטת MP4:
```bash
python enhance_lecture_audio.py "הרצאה 2.mp4"
```
